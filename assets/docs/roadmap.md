<!--Roadmap for repoScanner-->

## ✓ Completed

- JSON export with a machine-readable report.
- Terminal reporting in stats, raw/developer, and utility modes.
- Extended language support for 40+ extensions, including JavaScript, Go, Rust, and more.
- Shell wrapper with order-independent option parsing.
- Script-based benchmarking and precision profiling guidance.
- Optional native `libcvault` integration for optimized file operations.
- Shared native-helper wrapper with a transparent Python fallback.
- Per-process directory scan caching by absolute root path.
- PyPI packaging with wheel builds for supported platforms.
- CI/CD publishing workflow using `cibuildwheel`.
- Pytest coverage for dependency extraction, analyzers, directory scanning, and metrics.
